# Nguồn dữ liệu

File PDF để trong `data/raw/` (không đưa lên git). File này ghi lại nguồn của từng văn bản để người khác tải lại được và để biết văn bản nào còn hiệu lực.

Cột **Loại PDF**: `chữ` nếu bôi đen copy được chữ, `scan` nếu là ảnh chụp (cần OCR).

| doc_id (= tên file) | Tên văn bản | Số hiệu | Ngày ban hành | Hiệu lực từ | Thay thế văn bản | Loại PDF | Link nguồn | Ghi chú |
|---|---|---|---|---|---|---|---|---|
| | | | | | | | | |

## Cần tìm

- [ ] Quy chế đào tạo trình độ đại học của trường (bản đang hiệu lực)
- [ ] Quy chế đào tạo trình độ đại học của Bộ GD&ĐT (Thông tư 08/2021/TT-BGDĐT và các văn bản sửa đổi nếu có)
- [ ] Quy định học phí và miễn, giảm học phí năm học hiện tại
- [ ] Quy định xét, cấp học bổng khuyến khích học tập
- [ ] Quy định đánh giá kết quả rèn luyện
- [ ] Quy chế công tác sinh viên
- [ ] Quy định về chuẩn đầu ra ngoại ngữ, tin học (nếu có)
- [ ] Hướng dẫn đăng ký học phần, học lại, học cải thiện
- [ ] Sổ tay sinh viên

## Ghi chú về bản quyền

Văn bản quy chế thuộc về cơ quan ban hành. Repo chỉ lưu đường dẫn nguồn và dữ liệu đã xử lý phục vụ tìm kiếm, không phân phối lại file PDF gốc.
