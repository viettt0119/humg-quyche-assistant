# Quyết định kỹ thuật (ADR)

Mỗi quyết định quan trọng là một file ngắn, đánh số: `001-chon-llm.md`, `002-...`. Khi phỏng vấn được hỏi "sao em chọn X?", bạn mở file này ra là có câu trả lời.

## Mẫu

```markdown
# 00X. <Tên quyết định>

- **Ngày:**
- **Trạng thái:** đang cân nhắc / đã chọn / bị thay thế bởi 00Y

## Bối cảnh
Vấn đề là gì, ràng buộc là gì (chi phí, phần cứng, thời gian, tiếng Việt).

## Các lựa chọn
| Lựa chọn | Ưu | Nhược | Số đo nếu có |
|---|---|---|---|

## Quyết định
Chọn gì và vì sao.

## Hệ quả
Điều gì trở nên dễ hơn, khó hơn. Khi nào nên xem lại quyết định này.
```
